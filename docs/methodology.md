# 方法说明：诗词互动导览邀请试验的分析口径

本文档说明 `tourtrial` 工具回答什么问题、按什么口径估计、哪些结论不能推广。

## 1. 试验背景与核心风险

两版邀请（诗词互动 / 常规导览）**按班随机分配**。需要时刻记住三个设计事实：

1. **同校的班会挤同一批场次**，席位共享；
2. **先到先得**，先收到邀请的人可能占掉后来者的名额；
3. 真实世界会出错：邀请会发错、学生可能跨班跟随、场次可能满额、签到可能无法识别。

因此"领取邀请的班里来了多少学生"不能回答"要不要发到所有研学班"——
那只是一个条件均值，不含任何比较。所有结论都必须来自**随机分配形成的对照**。

## 2. 数据与事实表

学校交：`students.csv`（期初名册）、`allocation.csv`（原始分配，含场次与容量）。
场馆交：`attendance.csv`（签到）、`quiz.csv`（小测，与是否到馆分开记录、用同一份期初名册追踪），
以及可选的 `sessions.csv`、`bookings.csv`（预约结果）、`invitations.csv`（实际发放记录）。

`build-panel` 生成学生层面事实表，三条原则：

- **原始分组不可变**。`arm` 只来自 `allocation.csv`。发错邀请、跨班跟随、满额
  都记录在案，但谁也不许把学生从原分组移走（ITT 原则）。
- **三类事实分列**：`invite_received`（实际收到什么）、`slot_available`
  （有没有可用名额）、`attended`（最终有没有参加）各自独立、各自可空。
  空 = 未观测，不是"没有"。
- **无法识别的签到进入未匹配清单**，只按场次统计条数用于对账，
  绝不凭场次分给某个班。小测同理：名册外的成绩不进任何班。

## 3. 估计口径

### 3.1 估计量

对每个结局（到馆参与率、期末小测、小测作答率、进步分）：

```
y_i = 处理指示_i + 学校固定效应 + 误差
```

即**学校内部比较**：每所学校内处理班与对照班之差，再跨校汇总。
只有同时具备两组班级的学校才进入比较（缺一组的学校会被点名）。

### 3.2 不确定性：班级才是分配单位

学生不是独立随机——整个班被分到同一版本邀请。工具同时报告：

- **班级聚类稳健标准误（CR1 有限样本修正）**：置信区间与 p 值以此为准；
- **随机化推断**：在学校内对班级标签做置换（精确枚举或蒙特卡洛），
  给出不依赖大样本近似的 p 值。班级很少时（如每校一处理班一对照班），
  它能直接告诉你证据的上限——4 个班时双侧 p 最小也有 0.5；
- **朴素标准误**（把学生当独立个体）仅作对照展示，**不可取**。

班级数少于 10 时工具会警告聚类标准误可能失真，以随机化推断为准。

### 3.3 小测缺测：未测不算答错

期末未作答的学生**不计入**分数分析（更不是记 0 分）。主分析只用已测者，
并报告两组各自的作答率差异（这本身是一个 ITT 结局，提示选择性缺测）。
在此之上给出**可说明的敏感性范围**：

- **最好/最坏情形界**：缺测者按量表端点填补，给出效应估计的可行区间；
- **临界点 Δ**：若处理组缺测者的真实均分比同组已测者低 Δ 分
  （对照组缺测者等于已测均值），结论在 Δ 多大时失去统计显著、多大时变号；
  对称地也报告对照组缺测者不利的情形。

结论是否依赖对缺测者的乐观假设，由这两个数字直接回答。

## 4. 席位压力与干扰：效果只在原供给条件下成立

共享席位意味着干扰：一个班能否到馆，取决于同场次其他班（甚至外校）占了多少座。
因此试验比较**最多说明原供给条件下的效果**。`capacity` 报告每个场次的
容量、需求、每生席位、共用班数/校数、超员情况与未识别签到条数；
`bookings.csv` 提供时还会按 `requested_at` 重放先到先得，核对场馆状态是否自洽。

## 5. 扩场复核

`review` 为每所拟扩场学校汇总五类证据：**分配证据**（校内组别构成、
实际发放与随机分配的一致性）、**样本覆盖**（签到可匹配率、到馆者小测作答率）、
**席位压力**、**效果结论**（含敏感性范围）、**扩场方案核对**。

建议分三档：

- **批准扩场**：证据充分，且拟用场次落在试验比较支持的供给条件内；
- **退回待复核**：方案问题——直接沿用试验场次、每生席位低于试验最紧张水平、
  班级重叠超出试验观察上限、或与其他学校拟用场次共享席位。
  试验比较不支持这些新条件，**不能按一个平均提升自动增加发放量**；
- **证据不足-暂缓扩场**：分配证据或样本覆盖不达标——校内缺可比较组别、
  整班发错或错发率超阈值、签到可匹配率或作答率过低。

反过来，**单纯发错一封邀请不应使有足够证据的学校全部停试**：
孤立错发（低于阈值、非整班）只记警告，学生仍按原分组分析。

## 6. 签发与台账

`sign` 把决定追加到只增不改的 JSONL 台账：记录包含决定、理由、警告、
签发人、备注、输入数据指纹、代码版本以及**完整的证据快照**（签发时采用的
资料与判断一并留存）。补录小测或更正名额后重新评估，会生成新记录并以
`supersedes` 指向旧记录；**已发给学校的决定原样保留**，`history` 可查完整链条。

## 7. 已知边界

- 时段（slot）须唯一标识场次；不同场馆共用时段名时请先改名（如"周六上午·西廊"）。
- 校内每组仅 1 个班时，该校对聚类标准误的贡献依赖跨校合并，结论以随机化推断为主。
- 期初平衡表用于核查随机分配是否走样；协变量调整（以期初分数提高精度）暂未实现。
